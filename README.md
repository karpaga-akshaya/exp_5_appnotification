# exp_5_appnotification

A simple Android application developed using **Android Studio and Kotlin** to demonstrate how to create and display notifications.

When the user clicks the **Show Notification** button, the application displays a notification with the message **"Welcome to My App"**.

---

## 📱 Application Preview

The application contains a simple interface with:

- Notification Demo title
- Show Notification button
- Android notification popup

---

## 🎯 Objective

The objective of this project is to understand and implement Android notifications using:

- Kotlin
- Android Studio
- XML layouts
- Notification Channels
- NotificationManager
- NotificationCompat
- Notification Permissions
